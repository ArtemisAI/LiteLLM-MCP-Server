# Tool: Public

**Description:** This tool provides a set of functions to interact with the public endpoints of the LiteLLM API. It allows you to retrieve information about the public model hub.

**Functions:**

- `get_public_model_hub()`: Retrieves the public model hub. This function uses the `/public/model_hub` endpoint.
- `get_public_model_hub_info()`: Retrieves information about the public model hub. This function uses the `/public/model_hub/info` endpoint.

**API Endpoints:**

- **GET /public/model_hub**: Retrieves the public model hub.
- **GET /public/model_hub/info**: Retrieves information about the public model hub.
