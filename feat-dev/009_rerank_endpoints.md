# Tool: Rerank

**Description:** This tool provides a set of functions to interact with the rerank endpoints of the LiteLLM API. It allows you to rerank a list of documents based on a query.

**Functions:**

- `rerank(documents, query)`: Reranks a list of documents based on a query. This function uses the `/rerank`, `/v1/rerank`, and `/v2/rerank` endpoints.

**API Endpoints:**

- **POST /rerank**: Reranks a list of documents based on a query.
- **POST /v1/rerank**: Reranks a list of documents based on a query.
- **POST /v2/rerank**: Reranks a list of documents based on a query.
