# Tool: OCR

**Description:** This tool provides a set of functions to interact with the OCR endpoints of the LiteLLM API. It allows you to extract text from documents and images.

**Functions:**

- `ocr(document)`: Extracts text from a document or image. This function uses the `/ocr` and `/v1/ocr` endpoints.

**API Endpoints:**

- **POST /ocr**: Extracts text from a document or image.
- **POST /v1/ocr**: Extracts text from a document or image.
